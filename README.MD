# E-Commerce Platform

Full-stack e-commerce web application built with Angular and ASP.NET Core Web API. The application features secure user authentication and role-based authorization, a product catalog with filtering, a fully functional shopping cart, order management, Stripe payment integration, discount coupons, and real-time notifications via SignalR. The backend follows Clean Architecture principles (API, Core, Infrastructure) and uses Entity Framework Core with SQL Server for data access. The entire application is containerized using Docker and includes a CI/CD pipeline via GitHub Actions.
